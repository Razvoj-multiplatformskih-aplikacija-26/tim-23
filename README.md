# tim-23
Kap - Zakazivanje dobrovoljnog davanja krvi. Davaoci krvi preko mobilne aplikacije pregledaju akcije, zakazuju termine uz proveru razmaka od poslednjeg davanja i otkazuju ih i bez signala, medicinsko osoblje u backoffice-u vodi dnevni raspored akcije, prijem i preglede davalaca, a veb prikazuje akcije po gradovima i zalihe krvi po krvnim grupama.
